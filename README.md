# Adam Bahloul Portfolio

Static portfolio website for Adam Bahloul, focused on embedded systems, robotics, AI, and creative development.

## Run locally

No dependencies are required:

```bash
npm run dev
```

Then open `http://localhost:3000`.

## Deploy with GitHub Pages

This repository is configured as a static site. In the GitHub repository settings, open **Pages**, select **Deploy from a branch**, choose `main`, and select the `/ (root)` folder.

The site entry point is [`index.html`](./index.html).
